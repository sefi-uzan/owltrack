# The overlay

The overlay sits on top of the game and shows your level, the EXP bar and four numbers:

| Stat | Meaning |
| --- | --- |
| **Last 5 min** | Net EXP gained in the last five minutes. |
| **EXP/h · 30m** | EXP per hour over the last 30 minutes, or the whole session if it's shorter. |
| **This session** | Net EXP since the session started, with the session length. |
| **To Lv. N** | Time to the next level at the current rate. |

The dot in the header is green while the game is being captured, amber while OwlTrack is looking for
it, and red on errors. A status line explains what's going on when nothing can be read yet.

## Shortcuts

| Shortcut | Action |
| --- | --- |
| <Kbd>Ctrl+Shift+L</Kbd> | Lock or unlock the overlay. Locked means click-through: clicks go to the game. |
| <Kbd>Ctrl+Shift+H</Kbd> | Show or hide the overlay. |

Unlock it to drag it somewhere else. While it's unlocked it gets a dashed gold outline and a settings
button. Lock it again when you're done so it can't steal clicks from the game.

## Tray menu

Right-click the OwlTrack icon in the system tray for:

- **Show overlay** and **Lock overlay (click-through)**, the same toggles as the shortcuts
- **Settings & calibration…**
- **Reset session**, to start counting from zero
- **Quit OwlTrack**

## Sessions

A session starts when OwlTrack first reads your EXP and keeps going until you reset it or quit.
Level-ups are handled, and deaths are counted as a loss. See [Accuracy](#/accuracy) for how.
