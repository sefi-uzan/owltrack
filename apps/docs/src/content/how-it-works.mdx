# How it works

OwlTrack can operate next to the game for a long time and use only a small quantity of computer
resources.

## Capture

OwlTrack gets a few images each second from the game window. It uses Windows Graphics Capture for
this. The maximum resolution of the images is 1440p. The overlay is not in these images.

For each image, OwlTrack copies only the regions that you calibrated. The graphics card copies them
into one small image. OwlTrack then changes each region to a black-and-white text image.

OwlTrack reads the text (OCR) only when the text image of a region changes. Usually, this occurs
only when a value changes.

If no region changes for 20 seconds, the capture rate decreases to 2 images each second. This occurs,
for example, when you are away from the game. At the next change, the capture rate goes back to the
usual rate.

## Text recognition

OwlTrack uses [Tesseract](https://github.com/tesseract-ocr/tesseract) to read the text. Tesseract is
part of OwlTrack and operates on your computer.

The EXP changes frequently. Thus, OwlTrack uses a faster procedure for the EXP:

1. Tesseract reads the EXP, and the tracker accepts the value.
2. OwlTrack cuts the image into digits. It records the shape of each digit with its value.
3. After approximately one minute in the game, OwlTrack knows all ten digits.
4. From then on, OwlTrack reads the EXP from the recorded shapes in approximately 1 ms.

Tesseract continues to read the level, the name and the digits that are not clear. It also reads one
EXP value in 100, to examine the recorded shapes.

OwlTrack keeps the recorded shapes in `glyphs.json`. Thus, it records them only one time.

## Resource usage

With a 4K game window, OwlTrack uses approximately 3 ms for each image. Tesseract stops after 60
seconds without use. It starts again when OwlTrack needs it. Electron, Chromium and the Windows capture
use most of the memory, not OwlTrack.
