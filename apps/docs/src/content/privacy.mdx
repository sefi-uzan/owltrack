# Privacy & security

**OwlTrack operates fully offline.** It does not send data to other computers. It has no telemetry,
no update checks and no accounts. The OCR occurs on your computer, and your settings stay on your
computer.

> This program will not transfer any information to other networked systems unless specifically
> requested by the user or the person installing or operating it.

## What OwlTrack reads

OwlTrack reads only the image of the game window. It processes only the regions that you draw.

OwlTrack does not do these actions:

- Read the memory or the files of the game.
- Put code into the game.
- Read the network traffic of the game.

## Code signing

[SignPath.io](https://about.signpath.io) gives free code signing. The certificate is from
[SignPath Foundation](https://signpath.org). SignPath signs only the files that the CI of the
repository makes from its source code. A person approves each signing request manually.
