# Introduction

OwlTrack is an overlay for MapleStory on Windows. The overlay stays on top of the game window. It
shows how fast you get EXP and when you get to the next level.

<Figure src="screenshots/overlay.png" alt="The OwlTrack overlay with the level, the EXP bar and four values" width={372}>
  The OwlTrack overlay
</Figure>

## What OwlTrack shows

| Value | Description |
| --- | --- |
| **Last 5 min** | The EXP that you got in the last 5 minutes. |
| **EXP/h** | Your EXP for each hour. OwlTrack uses the last 30 minutes to calculate this value. |
| **This session** | The EXP that you got since the session started, and the length of the session. |
| **To Lv. N** | The time until the next level, at your current EXP/h. |

## How OwlTrack gets the values

OwlTrack reads the level, the character name and the EXP from the image of the game window. It does
not read the memory, the files or the network traffic of the game. The text recognition (OCR) occurs
on your computer.

<Note>
OwlTrack is free and open source (MIT license). It is a fan-made tool. NEXON does not make or approve
OwlTrack.
</Note>

## Requirements

- Windows 10 or Windows 11, 64-bit.
- MapleStory in **windowed** mode or **borderless** mode. The overlay cannot show on top of a game in
  exclusive fullscreen mode.
