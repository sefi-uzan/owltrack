# Calibration

Use the **Calibrate** tab of the settings window to tell OwlTrack where the regions are. The badge
next to **Calibrate** shows how many of the three necessary regions are set.

<Figure src="screenshots/calibrate.png" alt="The Calibrate tab with the game image on the left and the Regions list on the right" width={1000}>
  The **Calibrate** tab
</Figure>

## Controls

| Control | Function |
| --- | --- |
| **Grab frame** | Gets a new image of the game window. |
| Zoom slider | Makes the image larger, so that you can draw more accurately. |
| **Threshold** | Sets the brightness limit between the text and the background. |
| Bin icon | Removes the box of the selected region. |

## Draw a region again

OwlTrack keeps the boxes relative to the game window. If you move the game window, the boxes stay
correct.

If you change the resolution or the UI scale of the game, draw all the boxes again:

1. Click **Grab frame**.
2. In the **Regions** list, click the region.
3. On the image, drag a new box around the region.
4. Do steps 2 and 3 again for each region.

## Adjust the threshold

OwlTrack changes each region to a black-and-white image before it reads the text. The threshold is
the brightness limit between the text and the background. The preview below the region shows this
black-and-white image.

| Problem in the preview | Action |
| --- | --- |
| Letters have gaps or are missing. | Decrease the threshold. |
| The background shows as black areas. | Increase the threshold. |

The default values are correct for most computers. The default threshold of **Job + name** is low
because thin lines, for example the bar of the letter `f`, are lost above 120.

## Correct the character name

The OCR can mix letters that look almost the same in the game font, for example `f` and `t`, or `l`
and `I`. To correct the name, do one of these procedures:

- In the settings window, open **Overlay**. Type the correct name in **Character name**.
- On the overlay, move the pointer to the name. Click the pencil icon and type the correct name.

OwlTrack keeps the correction for the name that it read. The correction applies only to that
character.

## Count mesos (experimental)

OwlTrack can count the mesos from the "You have gained mesos (+52)" notices on the right of the screen.

1. In the **Regions** list, set the switch next to **Meso notices** to on.
2. On the image, drag a box around the meso notices.

<Note>
The meso count is not exact. OwlTrack ignores the notices that the OCR cannot read clearly, so the
count is lower than the real value. OwlTrack does not count item drops. The EXP always comes from the
EXP bar, not from the notices.
</Note>
